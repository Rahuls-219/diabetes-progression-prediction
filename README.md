# Diabetes Progression Prediction Using Machine Learning

## Project Overview

This project focuses on predicting disease progression using patient health measurements and machine learning.

The project uses the Diabetes dataset available through Scikit-learn's `load_diabetes()` function.

The main objective is to explore the dataset, understand relationships between the features and disease progression, and build a Linear Regression model to generate predictions.

## Objectives

- Load and understand the Diabetes dataset
- Perform Exploratory Data Analysis (EDA)
- Analyze correlations between features and the target
- Train a Linear Regression model
- Evaluate the model using R², MAE, and RMSE
- Identify influential features
- Compare actual and predicted values
- Analyze prediction errors

## Dataset

The project uses the `load_diabetes()` dataset from Scikit-learn.

The dataset contains health-related measurements including age, sex, BMI, blood pressure, and six serum measurements.

The target variable represents disease progression after one year.

The main machine learning model used in this project is:
